What this means for a “neutral chrome” refresh

  • Surfaces already lean slate/white — keep chrome quieter (zinc/neutral, softer borders, less card chrome).
  • Let screenshot content + selected tab/app identity own accent color.
  • Replace heavy primary CTAs on browse surfaces with outline/ghost; reserve filled primary for rare actions.
  • Promote Tabs (or segmented control) for flows so selection state can be the colorful signal.

Recommended refresh direction

Not implementing yet — design intent for the gallery chrome so apps and tabs carry color.

Today
  • shadcn slate defaults; near-black filled primary
  • Every tile is a bordered card + hover shadow
  • Flow filtering via dropdown, not tabs
  • Inter everywhere; no brand type voice
  • Clerk green ≠ app primary (slate)
  • Dark tokens unused
Target (neutral gallery)
  • Zinc/neutral token set; primary = foreground ink, not brand hue
  • Quieter tiles: hairline borders or gap-only; no competing chrome color
  • Flow tabs / segmented control as the colorful selection layer
  • Optional: app accent from logo/metadata for active dapp context
  • Unify Clerk + status accents into semantic tokens
  • Keep screenshots full-bleed in tile; metadata secondary
